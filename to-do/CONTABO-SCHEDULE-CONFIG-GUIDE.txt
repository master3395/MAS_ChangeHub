HOW TO CHANGE THE SNAPSHOT TIME
═══════════════════════════════════════════════════════════════════════

STEP 1: Edit config.php
────────────────────────
nano /home/contabo-snapshots/config.php

STEP 2: Change SNAPSHOT_TIME
─────────────────────────────
// Schedule Configuration
define('SNAPSHOT_TIME', '01:00'); // Change this to your desired time

Examples:
  define('SNAPSHOT_TIME', '00:00');  // Midnight
  define('SNAPSHOT_TIME', '01:00');  // 1:00 AM (current)
  define('SNAPSHOT_TIME', '02:00');  // 2:00 AM
  define('SNAPSHOT_TIME', '03:30');  // 3:30 AM
  define('SNAPSHOT_TIME', '23:00');  // 11:00 PM

STEP 3: Apply the Configuration
────────────────────────────────
cd /home/contabo-snapshots
./apply_config_schedule.sh

DONE! ✅ The cron job is automatically updated.

═══════════════════════════════════════════════════════════════════════
CONFIGURATION OPTIONS IN config.php
═══════════════════════════════════════════════════════════════════════

SNAPSHOT_TIME
  When to run the snapshot (24-hour format HH:MM)
  Example: '01:00', '13:30', '23:45'

AUTO_APPLY_SCHEDULE
  true  → Automatically apply schedule from config.php
  false → Use manual cron configuration

MAX_SNAPSHOTS_PER_INSTANCE
  How many snapshots to keep (older ones auto-deleted)
  Default: 3

SNAPSHOT_NAMES
  Exact name for each retained snapshot (3 entries when MAX is 3)
  Example: 'CP-2-4-4-Alma-sieve-1', 'CP-2-4-4-Alma-sieve-2', ...

SNAPSHOT_NAMES_BY_INSTANCE
  Optional per-instance overrides (display name => array of names)

SNAPSHOT_DESCRIPTION_TEMPLATE
  Text sent to Contabo when creating; use {date} for timestamp

RECOMMENDED TIMING
═══════════════════════════════════════════════════════════════════════

✅ RECOMMENDED: 01:00 GMT+2 (Current)
   • Runs 1 hour after Internet Archive midnight snapshot
   • Good separation from other systems
   • Off-peak hours for better performance

✅ ALTERNATIVE: 02:00 GMT+2
   • Even more separation from Internet Archive
   • Still in off-peak hours

⚠️  AVOID: 00:00 GMT+2
   • Conflicts with Internet Archive snapshot
   • Both systems running at same time

═══════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: Schedule not changing
Solution: Make sure AUTO_APPLY_SCHEDULE is true and run apply script
  grep "AUTO_APPLY_SCHEDULE" /home/contabo-snapshots/config.php
  ./apply_config_schedule.sh

Problem: Cron not running
Solution: Check cron service
  systemctl status crond
  systemctl restart crond

Problem: Snapshots not appearing
Solution: Check logs for errors
  tail -100 /home/contabo-snapshots/logs/snapshot-manager.log
